# 📱 Diagrama UML - iPhone

Este projeto representa a modelagem UML do componente iPhone, com base na apresentação original feita por Steve Jobs no lançamento de 2007.

O iPhone é modelado com três funcionalidades principais:

- 🎵 **Reprodutor Musical**
  - `tocar()`
  - `pausar()`
  - `selecionarMusica(String musica)`
- 📞 **Aparelho Telefônico**
  - `ligar(String numero)`
  - `atender()`
  - `iniciarCorreioVoz()`
- 🌐 **Navegador na Internet**
  - `exibirPagina(String url)`
  - `adicionarNovaAba()`
  - `atualizarPagina()`
